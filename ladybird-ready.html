Test your own site

Ladybird is in alpha and the team is asking developers to try their own sites and report breakages. You can run the same check I did:

  1. Download Ladybird for macOS (Apple silicon) or Linux from ladybird.org/download.
  2. Launch it headless: /Applications/Ladybird.app/Contents/MacOS/Ladybird --headless=screenshot --screenshot-delay 8 --window-width 1280 --window-height 800 --screenshot-path ./shot.png https://yoursite.com
  3. Check the screenshot. If it's blank or broken, file an issue at github.com/LadybirdBrowser/ladybird/issues with the URL and the screenshot.

Ladybird also supports WebDriver and the Firefox DevTools protocol, so the whole thing can be automated.
